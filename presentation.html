❌ ปัญหาที่พบ (Pain Points)

เมื่อเดินทางท่องเที่ยว มักถ่ายรูปไว้เยอะมาก แต่ภาพถูกกระจัดกระจายอยู่ใน คลังภาพ (Gallery) ทำให้ลืมชื่อสถานที่ ลืมความรู้สึก หรือจำพิกัดตำแหน่งไม่ได้เมื่อเวลาผ่านไป

🎯 วัตถุประสงค์ในการสร้างแอป

เพื่อสร้างพื้นที่ส่วนตัวในการบันทึกไดอารี่การเดินทางแบบครบวงจร (All-in-One Journaling) ทั้งรูปภาพหลายใบ, อารมณ์ (Mood), บรรยากาศ, ค่าใช้จ่าย และพิกัด GPS บนระบบ Android/iOS

📝 ฟีเจอร์หลัก 1: ระบบเพิ่มบันทึกความทรงจำสุดล้ำ

Feature 1
  • Location Autocomplete: มีรายชื่อสถานที่ตัวอย่าง (Preset List) และดึงประวัติสถานที่ที่เคยบันทึกมาแนะนำอัตโนมัติขณะพิมพ์
  • Multi-Image Picker: รองรับการอัปโหลดรูปภาพพร้อมกันได้หลายรูปต่อ 1 ทริป
  • Mood & Weather Tags: เลือกอารมณ์ (🥳, ☕, 🍕) และแท็กบรรยากาศ (☀️ แดดดี, 👫 ไปกับแฟน)
  • Rating & Expense: ให้คะแนนดาว (⭐1-5) และเลือกช่วงงบประมาณ (฿฿฿)
  • GPS Location Tracking: ดึงพิกัด ละติจูด/ลองจิจูด จริงจากอุปกรณ์

🎨 Card Design ระดับ Pro

แสดงการ์ดรายการทริปอย่างสวยงาม พร้อม Badge แสดงจำนวนรูปภาพรวม, แท็กอารมณ์ และวันที่บันทึก

🔍 Image Carousel Modal

เมื่อผู้ใช้กดแตะที่การ์ดสถานที่ จะเปิดหน้าต่าง Full Detail Modal ขึ้นมา พร้อมระบบ ปัดรูปภาพสไลด์ซ้าย-ขวา ดูภาพขนาดใหญ่ได้เต็มตา

📊 ฟีเจอร์หลัก 3: Dashboard สถิติ & โปรไฟล์ผู้ใช้

Feature 3
  • Travel Dashboard: สรุปสถิติการเดินทางจริงแบบ Real-time (จำนวนทริปทั้งหมด, รูปภาพรวมทั้งหมด, คะแนนดาวเฉลี่ย)
  • User Profile Customization: สามารถเปลี่ยนรูปโปรไฟล์จากคลังภาพ และแก้ไขชื่อผู้ใช้งานได้
  • Hardware API Integration: ตรวจสอบสถานะแบตเตอรี่คงเหลือด้วย `expo-battery`
  • Daily Travel Reminder: ปุ่มระบบจำลองส่งการแจ้งเตือนเตือนบันทึกประจำวัน
